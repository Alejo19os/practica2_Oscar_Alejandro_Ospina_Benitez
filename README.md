# Inventario de Productos - UCompensar 
#Oscar Alejandro Ospina Benitez

Aplicación web full-stack para la gestión y consulta de un inventario de productos, desarrollada con **Node.js + Express** en el backend y **HTML, CSS y JavaScript vanilla** en el frontend.

## 📋 Descripción

El sistema permite visualizar un listado de productos almacenados en una base de datos simulada (en memoria), consultar un producto específico por su ID, y presenta la información en una tabla estilizada y responsiva.

## 🚀 Tecnologías utilizadas

- **Backend:** Node.js, Express
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Datos:** Arreglo de objetos en memoria (simulación de base de datos)
